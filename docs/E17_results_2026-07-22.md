## Verdicts (per registration)

- **Batch Calibration (BC) is the adopted result.** Parameter-free, GPU-free,
  unsupervised: keep an assertion iff its verifier `p_yes` exceeds the model's own
  prior p̄ (mean `p_yes` over the model's test assertions) — the log-odds
  Batch-Calibration decision at 0.5 (Zhou et al., ICLR 2024). Positive credited
  gain for **all three** over-asserting models, above the +0.03 bar throughout:
  mistral **+0.118** and gemma **+0.107** (~+0.11, ≈ +40 % relative on a ~0.25
  baseline), llama **+0.065** (a smaller but clean gain, carried by mouse-human).
  Mean over the three ≈ **+0.097**. BC-cell (per-dataset prior) ≈ BC-model,
  marginally better.

- **Raw thresholding (V1, τ=0.5) fails because the `p_yes` scales are not
  comparable across models.** mistral's `p_yes` is compressed near 0 (p̄=0.025),
  so a global τ=0.5 rejects almost all *good* assertions → **−0.125**. This is the
  clearest single argument for BC: subtracting the per-model prior converts
  mistral's −0.125 into **+0.118**. (Diagnosis matches Surface-Form Competition /
  Calibrate-Before-Use; §1 of the synthesis.)

- **V3 (dev-tuned threshold) is unstable.** Dev (g1+g2) is =-heavy, pushing
  τ_v → 0 (keep almost everything); the frozen τ is then timid on test — rescues
  mistral only marginally (+0.022) and leaves llama/gemma gains on the table
  (+0.030 / +0.092). Dominated by BC on every model. Confirms: the fix is
  prior-subtraction, not a tuned cut.

- **The precise reasoner is the control.** gpt-oss does *not* over-assert;
  skeptical verification therefore removes mostly true positives (V1 −0.040). Its
  verdict is binary (no graded score → BC not applicable). Clean contrast:
  **verification helps over-asserting models, not the calibrated reasoner** — the
  mechanism (rejecting hallucinated FPs) is exactly what a precise model has few
  of. This mirrors E16, where pruning also helped only the over-asserters.

- **Direction symmetrization (SYM)** — reject if the *reverse* relation also
  scores YES — is credited-neutral to slightly positive (llama +0.109 vs V1
  +0.107) and does not change any verdict; kept as a descriptive secondary.

## Take-away for the thesis
E16 showed the None-oversaturation that collapses F1 is only fixable by *adding a
rejection signal*, not by pruning (H1/H3 below bar for the precise models). E17
supplies that signal: a **skeptical, hierarchy-contextualized verification pass**
whose output is **batch-calibrated per model**. This lifts credited macro-F1 for
every over-asserting model (mistral +0.118, gemma +0.107, llama +0.065; mean
≈ +0.10) with **zero tuned parameters and zero extra GPU beyond scoring the
already-asserted pairs**, and the reasoner control (gpt-oss, −0.040) confirms the
mechanism rather than a metric artefact. This is the single adopted precision
intervention of the thesis.
